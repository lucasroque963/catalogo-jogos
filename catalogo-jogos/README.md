# 🎮 GameHub

Aplicação web desenvolvida com **React** que consome a **RAWG API** para exibir informações sobre jogos.

O projeto permite pesquisar jogos, visualizar detalhes completos e salvar jogos favoritos no navegador utilizando `localStorage`.

## 🚀 Funcionalidades

- Buscar jogos por nome
- Listar jogos populares
- Visualizar imagem, nota, lançamento, gêneros e plataformas
- Página de detalhes de cada jogo
- Exibir desenvolvedora e nota do Metacritic
- Favoritar jogos
- Salvar favoritos com LocalStorage
- Página exclusiva de jogos favoritos
- Remover jogos dos favoritos
- Layout responsivo

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- CSS
- React Router DOM
- RAWG API
- LocalStorage
- Vite

## 🔗 API utilizada

Os dados dos jogos são obtidos através da **RAWG Video Games Database API**.
